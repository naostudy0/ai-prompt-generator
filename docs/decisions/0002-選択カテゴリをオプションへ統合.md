# 0002 選択カテゴリを名前付きオプションへ統合する

## 状態

採用。

## 背景

表情、視線、場所、構図、動作、従来オプションは、名前とタグ文面を登録し、今回使う候補を選んでpositiveへ出力する点で同じ目的を持つ。違いはカテゴリ名、表示順、単一選択か複数選択かであり、個別のモデル・API・画面を維持する必然性がなくなった。

一方、LoRAはファイル名、強度、タグ生成を持ち、トリガーと服装は特定LoRAへ従属する。これらは汎用オプションと異なる不変条件と変更理由を持つ。

## 判断

LoRA、LoRAトリガー、LoRAに必ず属する服装を専用モデルとして残す。それ以外のpositive用候補は、利用者が名前、選択方式、表示順を設定できるオプションブロックと、その中のオプション項目へ統合する。

ブロックと項目の並び順を保存対象とし、ドラッグまたは明示的な移動操作で変更できるようにする。項目はブロック間を移動できる。

## 影響

- 表情、視線、場所、構図、動作の専用更新モデル、API、テーブル、画面部品をオプションへ移行する。
- ブロックの選択方式によって単一選択と複数選択を表現する。
- positiveの出力順は、固定カテゴリ順ではなく保存されたオプションブロック順になる。
- 服装のLoRA関連を必須にし、LoRA削除時は所属服装も同じ整合性単位で扱う。
- F06とF07の目的はF08へ統合し、移行後の振る舞いはF08を正とする。
