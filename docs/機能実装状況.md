# 機能実装状況

機能ごとの実装状況を確認するための一覧。
仕様と設計の正本は[機能概要](spec/機能概要.md)と各詳細設計とし、この文書では進捗だけを管理する。

## 状況の定義

- **実装済み**：詳細設計の主要な受入条件に対応するアプリケーションコードとテストが存在する。
- **未実装**：詳細設計は存在するが、対応するアプリケーションコードが存在しない。
- **統合済み**：単独機能としては実装せず、後続機能へ仕様を統合している。
