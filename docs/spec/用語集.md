# 用語集

今回の文脈は「画像生成用プロンプトの準備」とする。各機能はこの文脈内で目的に応じて分ける。

| 用語 | コード上の表現案 | 意味 |
| --- | --- | --- |
| positive | `positive` | 画像生成ツールのpositive欄へ渡す文面 |
| negative | `negative` | 画像生成ツールのnegative欄へ渡す文面 |
| プロンプトの種別 | `PromptPolarity` | 文面がpositive／negativeのどちらに属するか |
| デフォルトプロンプト | `DefaultPrompt` | 普段使う文面のまとまり。F12導入後は各系統・各種別につき一つ |
| 系統 | `ModelFamily` | 人物・キャラクターLoRAの適用先を表す利用者登録の分類。Illustrious、anima、ponyなど。系統ごとにpositive／negativeのデフォルト文面を持つ |
| 有効系統 | `activeModelFamily` | 今回の出力に使う系統。人物LoRAを選択中はその所属先を用いる |
| デフォルトの編集内容 | `defaultPromptDraft` | 編集用テキストエリアの未保存の文面 |
| 選択状態 | `selected` | その文面を今回の表示結果に含めるかどうか |
| 出力プロンプト | `promptOutput` | 選択内容から作り、利用者が調整・コピーする文面 |
| セクション | `promptSection` | 各側の出力内で空行一つにより区切る文面のまとまり。初期はデフォルト文面が一つのセクションとなる |
| お気に入りプロンプト | `FavoritePrompt` | 後で再利用するために、完成したpositive／negative、登録時の選択状態、選択概要、任意の画像をまとめて保存したもの |
| 選択スナップショット | `FavoriteSelectionSnapshot` | お気に入り登録時の選択を復元するための識別子・強度と、登録時の内容を説明する表示名を保持した記録 |
| LoRA | `Lora` | 画像生成時に適用するLoRAファイルと、利用者が探すために付けた登録名の組。出力時はファイル名と強度からLoRAタグを作る |
| LoRAの用途 | `LoraKind` | LoRAを人物・キャラクター用または衣装用のどちらの選択方法で扱うかを示す区分 |
| LoRAファイル名 | `fileName` | LoRAタグへ埋め込むファイル名。利用者向けの登録名とは区別する |
| LoRA強度 | `strength` | LoRAタグで指定する0から1までの値。0.1刻みで選び、初期値は1とする |
| トリガー | `LoraTrigger` | 特定のLoRAに属する人物・キャラクターや髪型などの呼び出し文面。登録名と文面を持つ |
| 服装 | `OutfitPrompt` | 服装を指定する文面。登録名と文面を持ち、必ず一つの人物・キャラクターLoRAに属する |
| 衣装LoRA | `Lora`（`clothing`用途） | 衣装へ適用し、複数選択できるLoRA。選択ごとに強度と所属トリガーを指定する |
| 人物LoRA差し替えコピー | `characterLoraVariantCopy` | 一つの出力を基に人物・キャラクターLoRAと所属トリガーだけを候補用に差し替え、候補ごとのpositiveをコピーする操作 |
| 表情 | オプションブロック名 | 表情用に移行する`multiple`のオプションブロック |
| 視線 | オプションブロック名 | 視線用に移行する`single`のオプションブロック |
| 場所 | オプションブロック名 | 場所用に移行する`multiple`のオプションブロック |
| 構図 | オプションブロック名 | 構図用に移行する`single`のオプションブロック |
| 動作 | オプションブロック名 | 動作用に移行する`multiple`のオプションブロック |
| オプションブロック | `OptionPromptGroup` | オプション項目をまとめる、利用者が名前・選択方式・表示順を設定できる単位 |
| オプション項目 | `OptionPrompt` | 一つのオプションブロックに所属し、登録名・文面・表示順を持つ候補 |
| セクションナビゲーション | `sectionNavigation` | 入力セクションの名前を表示順に並べ、対象位置へ移動するための画面上の案内 |
| 選択概要 | `selectionSummary` | 現在選択中の登録名と設定値を入力セクション単位でまとめた、保存しない画面表示用の情報 |
| 選択方式 | `OptionSelectionMode` | ブロック内で最大一項目を選ぶ`single`または複数項目を選ぶ`multiple` |
| 表示順 | `position` | ブロックまたは所属ブロック内の項目を表示・出力する順序 |
| コピー | `copy` | 指定した側の出力欄の現在の文字列をクリップボードへ書き込む操作 |
| ComfyUIワークフロー | `ComfyUiWorkflow` | ComfyUIからAPI形式で書き出した実行グラフ。positive／negativeを設定する入力位置を本アプリの設定と対応付ける |
| ワークフロー入力マッピング | `WorkflowInputMapping` | ワークフロー内で本アプリが書き換えるノードIDと入力名の組。positive、negative、seed、checkpoint、sampler、scheduler、任意の保存先という役割で保持する |
| キュー送信 | `queuePrompt` | positive／negativeを設定済みワークフローへ適用し、ComfyUIの`POST /prompt`で実行待ちへ追加する外部副作用 |
| 差し替え送信対象 | `characterVariantQueueSelection` | 人物LoRAと所属トリガーの候補行のうち、一括キュー送信へ含めるかを表すブラウザー保存の選択状態 |
| 生成設定選択肢 | `GenerationSettingOption` | 系統ごとに登録するcheckpoint、sampler、schedulerの選択肢。人物LoRAは各種類を一つずつ参照する |
| checkpoint設定 | `checkpointOption` | ComfyUIで読み込むモデル名。系統ごとの選択肢から人物LoRAに一つ指定する |
| sampler設定 | `samplerOption` | ComfyUIのsampling方式名。系統ごとの選択肢から人物LoRAに一つ指定する |
| scheduler設定 | `schedulerOption` | ComfyUIのscheduler名。系統ごとの選択肢から人物LoRAに一つ指定する |
| 生成画像ディレクトリ名 | `outputDirectoryName` | ComfyUI送信時に任意で設定する`tmp/{fileName}`形式の保存先名。`fileName`は人物LoRAの拡張子を含まないファイル名 |
| タグ | — | 文面に含まれる語句。デフォルト編集では文面全体を一まとまりとして扱う |

デフォルトの「削除」は文面を空にすることを指す。「選択解除」は今回の出力に含めないことを指す。
保存した文面、編集中の文面、表示した出力、選択状態は、役割の異なる状態として扱う。
