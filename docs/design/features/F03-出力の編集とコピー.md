# F03 出力の編集とコピー

- 状態：草案。直接編集でデフォルトを変更しないことは確定。
- 関連：[機能概要](../../spec/機能概要.md)、[F01](F01-デフォルトプロンプト.md)、[F02](F02-プロンプトの選択と表示.md)。

## 目的と背景

表示したプロンプトを今回使いたい文面に調整し、画像生成ツールのpositive欄とnegative欄にそれぞれ貼り付けられるようにする。
必要に応じて個別の語句を削除できるよう、出力欄そのものを編集可能にする。

## 要件

| ID | 要件 |
| --- | --- |
| F03-R01 | positive／negativeの出力欄をそれぞれ編集可能なテキストエリアにする |
| F03-R02 | 各出力欄に独立したコピーボタンを置く |
| F03-R03 | コピー時点でその出力欄にある文字列をコピーする |
| F03-R04 | 一方の編集・コピーがもう一方の文面を変更しない |
| F03-R05 | 出力欄の直接編集では保存済みデフォルトを変更しない |
| F03-R06 | 参考画像に寄せた配置・配色・見出しで、画像生成ツールの貼り付け先との対応を示す |

参考画像とカード構成は[画面設計](../画面設計.md)を参照する。positiveを上の緑系カード、negativeを下の赤茶系カードとし、各カードに編集可能な出力欄とコピーボタンを置く。

## 操作の流れ

1. F02で表示された文面を確認する。
2. 必要なら出力欄で一部の語句を削除・変更する。
3. コピーしたい側のボタンを押す。
4. その側の現在の文面をクリップボードへ書き込む。
5. 画像生成ツールの対応する入力欄へ利用者が貼り付ける。

コピー対象は、保存済みデフォルトや生成直後の古い文字列ではなく、クリック時点のテキストエリアの値とする。

## 直接編集と保存の関係

直接編集は出力だけに反映し、普段使う文面の変更はF01の編集・保存で行う。
再表示時の出力置き換えはF02で扱う。
調整したプロンプト全体の保存・呼び出しは、別機能F04（お気に入り）として詳細化する。

## コピーの契約と画面状態（設計案）

| 条件 | 内容 |
| --- | --- |
| 事前条件 | 利用者がコピー対象の側を指定してボタンを押す |
| 不変条件 | positive／negativeそれぞれの出力が独立している |
| 事後条件 | 成功時、押した時点の対象文面がクリップボードへ渡され、対象側に成功を通知する |

コピー中・成功・失敗の通知は側ごとに扱い、書き込み完了後に成功を知らせる。
ブラウザーでコピーが許可されない場合は、文面を保持し、テキストエリアから手動で選択・コピーできるよう案内する。
空欄の場合はコピーボタンを無効化する。

## 実装上の責務案

出力の保持・編集・コピーはブラウザー側で扱う。
コピー関数には対象文字列を渡し、DOM操作とクリップボード書き込みを分ける。
出力の直接編集・コピーからF01の保存処理は呼び出さない。

## 受入条件

| 要件 | 操作 | 期待結果 |
| --- | --- | --- |
| R01・R03 | positiveの一語を削除してコピーする | 削除後の全文がコピーされる |
| R02・R04 | negativeのコピーを押す | negativeだけをコピーし、positiveの文面は変わらない |
| R02 | 対象の出力欄を空にする | その側のコピーボタンが無効になる |
| R03 | 改行・カンマを含む文面をコピーする | 出力欄の現在の文面に一致する |
| R03 | クリップボードへの書き込みが失敗する | 成功通知を表示せず、対象側に失敗と手動コピーの案内を表示する |
| R05 | 出力のpositiveを編集してからデフォルトを再取得する | 保存済みデフォルトは編集前と同じ文面である |
| R06 | 出力欄と参考画像を見比べる | 配置・配色・positive／negativeの見出しから貼り付け先が対応していると分かる |

文字列を受け取るコピー処理をテスト用の実装に差し替え、渡された値を明示した期待値で検証する。
実ブラウザーでは各側のコピー後にテキスト入力欄へ貼り付けて確認する。
実装ファイル・テストファイルは未作成。
