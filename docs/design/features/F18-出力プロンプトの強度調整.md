# F18 出力プロンプトの強度調整

関連文書：[機能概要](../../spec/機能概要.md)、[F03 出力の編集とコピー](F03-出力の編集とコピー.md)、[画面設計](../画面設計.md)

## 目的と背景

利用者は、生成したpositive／negativeプロンプトの一部を強調または弱調したい。
選択したタグを手作業で括弧と数値の構文へ書き換えず、ComfyUIの重み編集に近いキーボード操作で調整できるようにする。

現在の出力欄は編集可能な`textarea`であり、ブラウザーから選択範囲と修飾キーを取得できるため実現可能である。サーバーAPI、DB、ComfyUI APIの変更は必要としない。

## 要件と範囲

| ID | 要件 |
| --- | --- |
| F18-R01 | positive／negativeの出力欄で文字列を範囲選択し、`Command + ↑`で強度を0.05上げられる |
| F18-R02 | positive／negativeの出力欄で文字列を範囲選択し、`Command + ↓`で強度を0.05下げられる |
| F18-R03 | 強度は`(選択文字列:強度)`の形式で表し、強度が1になったときは強度指定の括弧を外す |
| F18-R04 | 調整後も対象文字列を選択状態に保ち、続けて強度を調整できる |
| F18-R05 | ショートカットによる変更を通常の出力欄編集と同様に扱い、お気に入り保存、コピー、ComfyUI送信へ反映する |

対象は出力欄で利用者が明示的に選択した一つの範囲とする。入力側の登録文面、LoRAタグの専用強度、未選択のカーソル位置からのタグ推定、複数の離れた選択範囲、刻み幅の設定画面は対象外とする。

## 操作と変換規則

1. 利用者がpositiveまたはnegativeの出力欄で、強度を変えたい文字列を範囲選択する。
2. `Command + ↑`または`Command + ↓`を押す。
3. 選択範囲が通常の文字列なら、現在の強度を1として0.05を加減する。
4. 選択範囲全体が`(本文:数値)`なら、その数値を現在の強度として0.05を加減する。
5. 計算結果が1なら`本文`だけに戻し、それ以外は`(本文:強度)`へ置き換える。
6. 書き換え後の本文または強度付き表現を再選択する。

例：

| 選択文字列 | 操作 | 変換後 |
| --- | --- | --- |
| `eyes closed` | `Command + ↑` | `(eyes closed:1.05)` |
| `eyes closed` | `Command + ↓` | `(eyes closed:0.95)` |
| `(eyes closed:1.05)` | `Command + ↓` | `eyes closed` |
| `(eyes closed:0.95)` | `Command + ↑` | `eyes closed` |
| `(eyes closed:1.05)` | `Command + ↑` | `(eyes closed:1.1)` |

選択範囲はそのまま本文として扱う。区切りのカンマを強度指定の外に残したい場合、利用者はカンマを含めずに選択する。たとえば`eyes closed,`のうち`eyes closed`だけを選ぶと、結果は`(eyes closed:1.05),`になる。

浮動小数点の誤差を避けるため、計算後は小数第2位で丸め、末尾の不要な0を表示しない。1だけは強度構文を取り除く。ComfyUIの同機能と同様に、強度値そのものへ明示的な上限・下限は設けない。

## 画面とキー操作

- 対象は`data-output-content`を持つpositive／negativeの出力欄だけとする。
- macOSの`Command`キーはKeyboardEventの`metaKey`で判定する。
- 範囲選択がない場合、または選択範囲が空白だけの場合は変更せず、矢印キー本来の動作を妨げない。
- 対象となる操作を処理した場合だけ既定動作を抑止する。
- 出力欄の近くにショートカットと0.05刻みであることを表示し、操作を発見できるようにする。
- ブラウザーやOSのショートカットと競合して処理できない環境は対象外とする。

## 実装上の責務

選択文字列の解析と強度の加減は、DOMへ依存しないJavaScript関数として`resources/js/`へ置く。出力欄のイベント処理はその関数へ選択文字列と増減方向を渡し、返された文字列で該当範囲を置換する。

置換後は既存の`input`時と同じ画面状態更新を行う。保存済みデフォルトや選択項目は変更せず、現在の出力欄だけを変更する。バックエンド、永続化モデル、APIは変更しない。

## 失敗時と境界

- 選択範囲が強度構文として解釈できない括弧を含む場合は、通常の文字列として全体を新しい強度構文で囲む。
- 選択範囲全体が`(本文:数値)`に一致するときだけ、既存の強度として解釈する。
- 本文が空、数値が有限数でない、または構文の本文が空の場合は変更しない。
- ショートカット操作はクライアント内で完結し、失敗を理由に入力内容を失わない。

## 受入条件と検証

| 要件 | 前提／操作 | 期待結果 |
| --- | --- | --- |
| R01 | 出力欄の`eyes closed`を選択して`Command + ↑`を押す | `(eyes closed:1.05)`へ変わる |
| R02 | 出力欄の`eyes closed`を選択して`Command + ↓`を押す | `(eyes closed:0.95)`へ変わる |
| R03 | `(eyes closed:1.05)`全体を選択して`Command + ↓`を押す | `eyes closed`へ戻り、括弧が外れる |
| R01 | `(eyes closed:1.05)`全体を選択して`Command + ↑`を2回押す | `(eyes closed:1.15)`になり、浮動小数点由来の桁が出ない |
| R04 | 選択範囲を一度調整する | 変換後の範囲が選択され、続けて上下操作できる |
| R05 | 強度を変更してコピー、お気に入り保存、ComfyUI送信を行う | 変更後の出力文字列が各処理に渡る |
| R01、R02 | 範囲選択せずにショートカットを押す | 出力内容は変わらず、通常のカーソル移動を妨げない |
| R01、R02 | 出力欄以外で同じキーを押す | この機能は動作しない |

JavaScript単体テストで変換規則と境界値を検証し、ページテストでキー入力、選択範囲の維持、既存の出力変更処理との連携を検証する。

## 設計上の判断と確認事項

- ComfyUIにはテキストウィジェットで`Ctrl + ↑／↓`により強度を調整する公式機能があり、刻み幅は設定可能である。本機能は操作感と`(本文:強度)`構文を合わせるが、ComfyUIのソースコードは流用せず、このアプリの出力欄向けに実装する。
- 依頼文の「0.5ずつ」は、提示例が`1.05`であるため、本設計では**0.05ずつ**の意味として扱う。
- Windows／Linux向けの`Ctrl + ↑／↓`対応を同時に行うかは未決事項とする。macOSの`Command + ↑／↓`だけで目的は満たす。
