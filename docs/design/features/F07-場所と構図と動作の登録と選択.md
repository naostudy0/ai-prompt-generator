# F07 場所・構図・動作の登録と選択

## 位置づけ

場所、構図、動作を専用カテゴリとして扱っていた仕様は、[F08 名前付きオプションブロック](F08-オプション項目の登録と選択.md)へ統合する。

場所は`multiple`の「場所」ブロック、構図は`single`の「構図」ブロック、動作は`multiple`の「動作」ブロックとして既存データを移行する。登録名、文面、選択数、文面整形、完全一致タグの重複除去という利用上の振る舞いはF08で維持する。

移行後の登録・編集・選択・並べ替え・出力・API・データ構造はF08を正とする。専用の`LocationPrompt`、`CompositionPrompt`、`ActionPrompt`、テーブル、APIは移行完了後に削除する。

この文書は機能IDと変更経緯を追跡するために残し、新しい実装判断の根拠には使用しない。
