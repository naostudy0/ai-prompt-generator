# F06 表情・視線の登録と選択

## 位置づけ

表情と視線を専用カテゴリとして扱っていた仕様は、[F08 名前付きオプションブロック](F08-オプション項目の登録と選択.md)へ統合する。

表情は`multiple`の「表情」ブロック、視線は`single`の「視線」ブロックとして既存データを移行する。登録名、文面、表情の複数選択、視線の単一選択、文面整形、完全一致タグの重複除去という利用上の振る舞いはF08で維持する。

移行後の登録・編集・選択・並べ替え・出力・API・データ構造はF08を正とする。専用の`ExpressionPrompt`、`GazePrompt`、テーブル、APIは移行完了後に削除する。

この文書は機能IDと変更経緯を追跡するために残し、新しい実装判断の根拠には使用しない。
