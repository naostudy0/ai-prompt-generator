# F02 プロンプトの選択と表示

- 関連：[機能概要](../../spec/機能概要.md)、[F01](F01-デフォルトプロンプト.md)、[F03](F03-出力の編集とコピー.md)。

## 目的

普段使う文面を一括で選択し、画像生成ツールへ渡すpositive／negativeの文面を同じ画面で確認できるようにする。

## 要件

| ID | 要件 |
| --- | --- |
| F02-R01 | 画面上部のpositive／negativeそれぞれに一つの「デフォルト」選択ボタンを置く |
| F02-R02 | ページロード時は両側とも選択状態にする |
| F02-R03 | ボタン操作で出力を作り、同じ画面の各出力欄へ表示する |
| F02-R04 | 各側のデフォルト文面を一まとまりとして選択に反映する |
| F02-R05 | 初見で入力側と分かる見出しを設け、カテゴリごとに選択ボタンを並べる |
| F02-R06 | 出力内のセクション間に空行を一つ入れ、文面のまとまりを見分けられるようにする |
| F02-R07 | 今回の選択状態と出力欄を一度にリセットし、LoRAセクションから選び直せる |

## 選択と表示の流れ

1. ページロードで両側を選択中にし、F01の文面取得を待つ。
2. デフォルトボタンを押すと、その側の選択／解除を切り替える。
3. 「プロンプトを表示」を押す。
4. 選択中の側には取得・保存が完了したデフォルト文面を、解除した側には空文字列を出力する。

初回の出力欄は空とし、取得完了後に表示ボタンを操作できる。
選択変更だけでは出力欄を書き換えず、表示ボタンで反映する。
初期のデフォルト文面はSeederで登録する。具体的な文面は[F01の初期データ](F01-デフォルトプロンプト.md#初期データ)に従う。文面が空でも選択状態を持てる。

## リセット

「プロンプトを表示」の近くに、今回の組み立てをやり直すための「リセット」ボタンを置く。リセットは次の状態変更を一度の操作で行う。

- positive／negativeの出力欄を空にする。利用者が出力欄を直接編集した内容も破棄する。
- positive／negativeのデフォルトを選択状態へ戻す。LoRA、トリガー、服装、衣装LoRAとそのトリガー、全オプションブロックの項目選択はすべて解除する。
- 人物・キャラクターLoRAの強度を未選択時の値である1へ戻し、衣装LoRAごとの今回の強度を破棄する。
- LoRA、衣装LoRA、検索を持つオプションブロックの検索文字列を空にし、取得済み候補をすべて表示する。
- 状態を更新した後、LoRAセクションの先頭へ滑らかにスクロールする。

リセットはブラウザー内の今回の選択と出力だけを変更する。保存済みデフォルト文面、LoRAや各候補の登録内容、APIやDBのデータは変更しない。操作後はすぐ選び直せるため確認ダイアログを表示せず、リセットボタンは「プロンプトを表示」と区別できる副操作の外観にする。

## 状態の分離

| 状態 | 変更する操作 |
| --- | --- |
| 保存済みデフォルト文面 | F01の保存成功 |
| デフォルト選択状態 | 各側の選択ボタン |
| 出力欄の文面 | 表示ボタン、F03の直接編集 |
| 今回の選択状態と出力欄 | リセットボタン |

デフォルトの編集中は表示操作を無効にし、保存またはキャンセルを終えてから表示する。
デフォルト保存時も既存の出力欄は保持し、次に表示ボタンを押したときに反映する。
デフォルトを編集・保存してから表示ボタンを押す場合、既存の出力があっても確認なしで更新する。
出力欄そのものを直接手編集した場合も、確認なしで現在の選択内容から作り直す。

## 契約と責務

事前条件は両側の文面取得が完了していること。不変条件は両側の文面・選択状態を別々に保持すること。
事後条件は、出力が選択状態と確定済み文面に一致していること。

取得済み文面から選択に応じて出力を作るJavaScriptの純粋な関数を設ける。
DOMの読み書きと文字列を作る処理を分け、入力と戻り値にpositive／negativeを明示する。
この処理に保存は伴わず、通信はF01の取得・保存に集約する。
他の選択項目が追加される際に、セクションの構成と表示順をその詳細設計で定める。

## セクション間の表示

各側の出力内で、文面のまとまりをセクションとして扱い、セクション間を空行一つ（改行二つ、`\n\n`）で区切る。
保存済み文面の末尾カンマを残したまま、その後に区切りを付ける。初期はデフォルトだけが一つのセクションとなる。
複数セクションになった場合の表示例：

```text
abc, def,

ghi, jkl,
```

表示上の区切りは出力文字列の改行として含め、コピー時にも引き継ぐ。
選択解除した項目や空の文面はセクションとして出力せず、出力の先頭・末尾には区切り用の空行を付けない。

## 画面と失敗時の扱い

入力欄の配置・カテゴリの見せ方は[画面設計](../画面設計.md)に従う。初期はデフォルトカテゴリのみとする。

選択状態は見た目と`aria-pressed`で示し、キーボードでも切り替えられるようにする。
positive／negativeのラベルを選択欄と出力欄の両方に表示する。
取得失敗時は表示操作を止めて再取得を案内し、既存出力がある場合は保持する。

## 受入条件

| 要件 | 操作 | 期待結果 |
| --- | --- | --- |
| R01・R02 | ページを開く | 各側に一つのデフォルトボタンがあり、両側とも選択中 |
| R05 | 入力欄を確認する | 入力の見出しがあり、各側のデフォルトカテゴリ内に選択ボタンがある |
| R03・R04 | 両側の取得完了後に表示する | positive／negativeにそれぞれの全文を表示 |
| R03・R04 | positiveだけ解除して表示する | positiveは空、negativeはそのデフォルト文面 |
| R03・R04 | 両側を解除して表示する | 両側とも空 |
| R03・R04 | 空のデフォルト文面を選択して表示する | 空文字列として表示できる |
| R03 | 表示済みの出力を直接手編集せず、デフォルトを編集・保存して再表示する | 確認を表示せず、保存後の文面で出力を更新する |
| R03 | 出力欄を直接手編集してから再表示する | 確認なしで現在の選択内容から出力を作り直す |
| R03 | デフォルトの編集欄を開く | 保存またはキャンセルを終えるまで表示操作が無効になる |
| R06 | セクションが一つの出力を表示する | 文面の末尾カンマを保持し、セクション間の区切りは生じない |
| R06 | 将来、`abc, def,`と`ghi, jkl,`の二つのセクションを表示する | `abc, def,\n\nghi, jkl,`となり、間に空行が一つある |
| R07 | 各カテゴリを選択して出力を直接編集した後にリセットする | 両出力欄とデフォルト以外の選択が空になり、positive／negativeのデフォルトは選択状態へ戻る。強度と検索条件が初期化され、LoRAセクションへスクロールする |
| R07 | 登録済み候補がある状態でリセットする | 保存済みデフォルト文面と各候補は変更されず、再選択できる |

出力作成関数は明示した入力値と期待値でテストし、選択操作と表示はブラウザーでも確認する。

## 関連機能との境界

出力の直接編集ではデフォルトを変更しない。お気に入りの呼び出しによる出力変更はF04で詳細化する。
